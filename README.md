M.A.I - это твой голосовой помощник для выполнение разных задач

==НЕОБХОДИМО==
для начало работы необходимо заполнить config.json путями до ваших приложений, скачать
M.A.I.exe и запустить после чего активируется твой микрофон и можно начать работу

== команды ==
1. Системные
 1) выключи ноутбук, выключи компьютер: выключить ваш ПК
 2) перезагрузи ноутбук, перезагрузи компьютер: перезагрузить ваш ПК
 3) закрой приложение: выключить открытое приложение
 4) усни: отправить ваш ноутбук в сон
 5) заблокируй ноутбук, заблокируй компьютер: заблокировать ваш ПК
 6) сверни все окна: свернуть все окна
 7) разверни, сверни: развернуть, свернуть окно

2. Приложения
 1) запусти vscode, включи vscode: открыть Visual Studio Code
 2) включи режим кодинга: запустить режим кодинга (VS Code + развернуть окно)
 3) открой steam, запусти steam, включи steam: открыть Steam
 4) запусти музыку, включи музыку: запустить музыку
 5) запусти песню, останови песню: воспроизвести/поставить на паузу
 6) следующая песня: следующий трек
 7) предыдущая песня: предыдущий трек

3. Веб
 1) включи кино, открой кино, запусти кинопоиск, включи кинопоиск: открыть Кинопоиск
 2) открой браузер, включи браузер, запусти браузер: открыть браузер
 3) включи youtube, запусти youtube, открой youtube: открыть YouTube
 4) включи нейросеть: открыть DeepSeek
 5) найди в ютубе: поиск в YouTube
 6) найди в гугле: поиск в Google
 7) открой заметки: открыть заметки

4. Прочее
 1) сделай скриншот: сделать скриншот экрана
 2) открой диспетчер задач: открыть диспетчер задач
 3) запомни: сохранить заметку

== примечание ==
для выполнение команд необходимо точно назвать команду
